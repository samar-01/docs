# SnappyXO Arduino Libraries

Welcome to the documentation for the SnappyXO Arduino library ecosystem. These libraries make it easy to build Bluetooth-controlled robots and other interactive Arduino projects.

---

## Libraries

### [MicroBlue](microblue/index.md)

Bluetooth Low Energy communication between the **MicroBlue mobile app** and Arduino boards. Supports HM-10 modules and the built-in BLE radio on the UNO R4 WiFi.

[Get started](microblue/getting-started.md) | [API Reference](microblue/api-reference.md) | [Examples](microblue/examples.md)

---

### [SnappyXO Shield](snappyxoshield/index.md)

Simplified motor control for the **SnappyXO Motor Shield**. Full-speed and variable-speed movement commands, plus a joystick-style differential drive function.

[Get started](snappyxoshield/getting-started.md) | [API Reference](snappyxoshield/api-reference.md) | [Examples](snappyxoshield/examples.md)

---

## Installation

Both libraries can be installed from the **Arduino Library Manager** (Sketch → Include Library → Manage Libraries).

| Library | Version | Search name | GitHub |
|---------|---------|-------------|--------|
| MicroBlue | 2.0.0 | `MicroBlue` | [snappyxo/microblue-arduino](https://github.com/snappyxo/microblue-arduino) |
| SnappyXO Shield | 0.2.0 | `SnappyXOShield` | [snappyxo/SnappyXOShield](https://github.com/snappyxo/SnappyXOShield) |
