# SnappyXO Documentation

Welcome to the SnappyXO documentation. Find guides for both the software libraries and hardware products below.

---

## Software

### [MicroBlue](software/microblue/index.md)

Bluetooth Low Energy communication between the **MicroBlue mobile app** and Arduino boards. Supports HM-10 modules and the built-in BLE radio on the UNO R4 WiFi.

[Get started](software/microblue/getting-started.md) | [API Reference](software/microblue/api-reference.md) | [Examples](software/microblue/examples.md)

---

### [SnappyXOShield](software/snappyxoshield/index.md)

Simplified motor control for the **SnappyXO Motor Shield**. Full-speed and variable-speed movement commands, plus a joystick-style differential drive function.

[Get started](software/snappyxoshield/getting-started.md) | [API Reference](software/snappyxoshield/api-reference.md) | [Examples](software/snappyxoshield/examples.md)

## Library Installation

Both libraries can be installed from the **Arduino Library Manager** (Sketch → Include Library → Manage Libraries).

| Library | Version | Search name | GitHub |
|---------|---------|-------------|--------|
| MicroBlue | 2.0.0 | `MicroBlue` | [snappyxo/microblue-arduino](https://github.com/snappyxo/microblue-arduino) |
| SnappyXOShield | 0.2.0 | `SnappyXOShield` | [snappyxo/SnappyXOShield](https://github.com/snappyxo/SnappyXOShield) |
