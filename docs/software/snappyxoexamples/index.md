# SnappyXOExamples

A collection of example sketches for SnappyXO hardware and libraries. Useful as a starting point for common robot behaviours.

**GitHub:** [github.com/snappyxo/snappyxoexamples](https://github.com/snappyxo/snappyxoexamples)

---

## Installation

**Via Arduino Library Manager (recommended)**

1. Open the Arduino IDE
2. Go to **Sketch → Include Library → Manage Libraries**
3. Search for `SnappyXO Examples`
4. Click **Install**


---

## Accessing Examples

Once installed, all examples are available via **File → Examples → SnappyXOExamples** in the Arduino IDE.
